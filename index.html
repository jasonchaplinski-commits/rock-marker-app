To share your map live with others, everyone pastes the same Firebase settings and types the same farm code into their own copy of this app. One person sets up the free Firebase project (~5 minutes, no cost, no credit card):
  1. Go to console.firebase.google.com, sign in, and click "Add project" (name it anything, Analytics can be off).
  2. In the left sidebar, look for Databases & Storage (Firebase has moved this around — if you don't see that exact label, look for anything mentioning "Firestore") → Firestore → Create database → pick a location → start in production mode → Create.
  3. Open the "Rules" tab of Firestore, replace the contents with the rule below, and click Publish:
    rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /farms/{farmCode}/{collection}/{docId} { allow read, write: if true; } } }
  4. Go back to your project's main Overview page. You'll see a row of small platform icons (iOS / Android / web) — click the web icon (</>) to add a web app (if you don't see it there, look for an "Add app" button, or the gear icon → Project settings → "Your apps" further down the page). Give it any nickname → Register app → copy the firebaseConfig block shown → paste it above.
  5. Pick a farm code that isn't easy to guess (anyone who has both the code and these settings can see and edit this map) and tap Connect. Text or email the same settings + code to whoever else should share it.
